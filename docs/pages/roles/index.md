# Roles & Responsibilities: Who Keeps the System Running

LigiOpen works best when every role understands its lane.

## Role overview

## Super Admin

The system governor.

Owns policy direction, high-level access control, and exceptional intervention when normal operations cannot resolve an issue.

## League Admin

The competition operator.

Owns season execution, participation quality, fixture governance, result confidence, and dispute direction.

## Club Admin

The club-side operations leader.

Owns team readiness, roster quality, and communication response to league operations.

## Content Admin

The match information coordinator.

Helps ensure match updates are reliable and public-facing records remain coherent.

## Officials

The fairness guardians.

Protect match legitimacy through officiating readiness and disciplined role execution.

## Players

The sporting core.

Contribute by keeping availability and participation responsibilities clear.

## Why this role model matters

Many football conflicts are not about rules. They are about unclear ownership.

Clear role boundaries reduce friction, speed up decision-making, and improve trust.

## Decision clarity matrix (plain language)

- Competition structure decisions: Super Admin + League Admin
- Team participation decisions: League Admin
- Club roster readiness: Club Admin
- Match-day info flow: Content Admin + Officials
- Final match governance: League Admin + Officials

## Common failure pattern

When everyone can “do everything,” no one is accountable.

Use role clarity as a discipline, not a suggestion.
