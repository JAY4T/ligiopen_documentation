# LigiOpen Documentation

Welcome to the LigiOpen documentation repository! This is a GitHub Pages site that provides comprehensive, user-friendly documentation for the LigiOpen sports management platform.

## 🎯 Purpose

This documentation is designed for **everyone** — not just developers. Whether you're:
- A league administrator setting up competitions
- A club manager registering your team
- A referee learning how to submit results
- A sports enthusiast understanding how league management works

...you'll find clear, story-driven explanations here.

## 📚 Documentation Structure

- **index.md** - Homepage with overview and quick navigation
- **getting-started.md** - Complete introduction with end-to-end season scenario
- **user-roles.md** - Explanation of all user roles and permissions
- **leagues-competitions.md** - How leagues, seasons, and competitions work
- **clubs-teams.md** - Club registration and team management
- **players.md** - Player registration, transfers, and eligibility
- **fixtures-matches.md** - Fixture generation and match management
- **standings.md** - Standings calculation and rankings
- **officials.md** - Referee management and result submission
- **venues.md** - Venue and stadium management
- **multi-sport.md** - How LigiOpen supports rugby, basketball, volleyball, etc.

## 🎨 Features

- **Story-driven**: Real scenarios with Kenyan names and contexts
- **Visual**: Clean, modern design with Kenyan flag colors
- **Comprehensive**: No bare minimum explanations — deep, thorough coverage
- **Accessible**: Written for laypeople, not technical users
- **Multi-sport**: Explains how features apply across different sports

## 🇰🇪 Kenyan Context

This documentation is specifically written for the Kenyan sports ecosystem, referencing:
- Kenyan leagues (FKF Premier League, Kenya Cup, etc.)
- Kenyan teams and locations
- County-level football associations
- Grassroots to professional competition structures

## 🚀 Viewing the Documentation

### Locally
```bash
# If you have Jekyll installed
bundle install
bundle exec jekyll serve

# Then visit http://localhost:4000
```

### On GitHub Pages
Once pushed to GitHub and Pages is enabled, the site will be available at your configured URL.

## 🛠️ Technical Details

- **Framework**: Jekyll (GitHub Pages compatible)
- **Theme**: Custom theme with Cayman-inspired layout
- **CSS**: Custom styling in `/assets/css/style.css`
- **JavaScript**: Interactive features in `/assets/js/main.js`
- **Logo**: LigiOpen logo in `/assets/images/`

## 📝 Contributing

To update or add documentation:
1. Edit the markdown files
2. Follow the existing structure and styling
3. Use the established div classes: `scenario`, `workflow`, `card`, `info-box`, `tip-box`, `warning-box`
4. Keep the Kenyan context and story-driven approach
5. Test locally before pushing

## 🎓 Style Guide

- Use emoji icons for visual interest (⚽ 🏉 🏀 etc.)
- Include real Kenyan names in scenarios (Peter Odhiambo, Mary Akinyi, etc.)
- Reference actual Kenyan locations (Kisumu, Nairobi, Mombasa, etc.)
- Write in simple, clear language — no technical jargon
- Include tables for structured data
- Use workflow steps for processes
- Add info boxes for key concepts
